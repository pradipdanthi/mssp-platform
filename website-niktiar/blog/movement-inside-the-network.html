Seeing movement inside the network

Once they are inside, the firewall at the front door is no longer on the path.

28 October 2026 · 3 min read · Kevantic Cyber Security

A stolen laptop is rarely the destination. The person using it looks for the file server, the backup, the identity system, the jump host into the plant. That walk from system to system is inside the building. The firewall on the internet edge is no longer standing on the path.

Two patterns worth naming

Lateral movement is the walk: one computer using another, often with a real account, toward the system that would hurt if it stopped. Beaconing is the quiet repeat call a compromised computer makes to its controller, on a schedule, hoping to look like ordinary traffic. Both can be invisible to a tool that only watches the front door.

Why this is a network job

NikTiar DeepSight NDR inspects that internal traffic. It is a Platinum capability because it needs the network, not only the laptop. The Cloud SOC reads it next to identity alerts and the endpoint. A graph with no case owner is still just a graph.

Identity tells you the account looked wrong. The network tells you where it walked. Containment, when the tier includes it, stops the walk: the computer is marked isolated only after the endpoint confirms it. Ransomware is an operations problem covers why that confirmation matters.

What the SOC should be able to say

A useful network finding is a sentence. “This finance laptop, with this account, spoke to the backup server at this hour, which it does not usually do.” Or: “This plant PC has been calling out on a steady timer since Tuesday.” NikTiar DeepSight NDR is there to support that sentence. The Cloud SOC turns it into a case, next to the identity story and the endpoint story, instead of leaving it as a chart.

This is a Platinum-tier capability because it watches the network itself. A company whose risk is mostly mailbox fraud may live well on identity and incident response. A company whose risk is a walk toward the backup, the domain, or the line should not pretend the front-door firewall saw that walk.

If the sentence cannot be written, do not add another dashboard. Fix retention and placement first, so the traffic that matters is actually visible to DeepSight and the raw record still sits on the NikTiar Edge Node.

If your current service can describe the login and cannot describe the next computer that login touched, you are watching the door and not the hallway.
