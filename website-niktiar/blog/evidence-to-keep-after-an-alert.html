The evidence to keep after an alert

Two weeks later the board asks what was touched. “We think” is not an answer.

28 October 2026 · 3 min read · Kevantic Cyber Security

An alert without a record is a rumour by Thursday. The board, the insurer, or the customer asks what was touched, and the only honest sentence left is “we think.” Forensics is the discipline of keeping enough of the story that the sentence can be specific: which account, which hour, which process.

What is worth keeping before anything goes wrong

  • Sign-in history, including the approvals, not only the failures.
  • Admin logins to the edge devices and remote gateways.
  • Enough endpoint history to see which process started which child, for long enough that a slow intrusion is still visible.

You do not need to export every log to a vendor’s cloud to be allowed to ask what happened. That choice is the subject of where security logs should live.

How an investigation is supported

NikTiar Spectre DFIR supports the investigation: process trees, canary files that light up if someone touches a bait, and a human investigator when the case needs one. The raw material stays on the NikTiar Edge Node. On the threat-intelligence service, a new indicator can be checked back across about 90 days of retained telemetry, which is only useful if those days were actually kept.

What you should receive when a case closes

You should be able to say, without opening a raw log, what was accessed, whether it left the company, what was contained, and what still needs a human decision. The technical tree — which process started which program — stays available to the investigation. NikTiar Spectre DFIR is how Kevantic supports that tree, including canaries that light up if someone touches a bait left for exactly that purpose. You do not need a procedure manual to demand the plain-English version.

You should also know the limits. A record that was never collected cannot be invented after the fact. Sign-in history, edge admin history, and endpoint history have to be kept on purpose, on the NikTiar Edge Node, for long enough that a slow intrusion is still inside the window. Threat intelligence sweeps of about 90 days only help if those days exist.

Insurers and customers ask these questions later, in calmer language. Answering them from memory is how companies end up arguing with their own timeline.

Decide the retention question on a quiet Friday. During an incident, it is already too late to wish the logs existed.
