# MSSP Endpoint Onboarding — Telemetry Configuration Pack

This package standardizes process, file, and network telemetry so the
control plane can build process trees and containment context.

Contents (by OS):
- windows/ — process telemetry XML + agent parameters
- linux/   — inventory / FIM / network pack + agent parameters
- macos/   — inventory / FIM / network pack + agent parameters

Install notes are inside each OS folder (INSTALL.txt).
