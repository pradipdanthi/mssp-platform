# KB-114 — NikTiar Secure Edge (Coraza CRS + hybrid multi-tenant)

**Status:** Lab feature-rich MVP (2026-10-25) — Coraza CRS Caddy + CrowdSec + hybrid site map.  
**Product:** Optional **add-on on any tier**. Distinct from sovereign Edge Node (EDR).  
**Code:** `niktiar-secure-edge/`, `backend-api/app/api/routes/secure_edge.py`, `postgres/init/050_*.sql` + `051_*.sql`.

---

## 1. Stack (current)

| Layer | Component |
|---|---|
| WAF | **`ghcr.io/coreruleset/coraza-crs:caddy-alpine`** (Coraza + OWASP CRS) |
| Edge proxy | Caddy 2 (Host-based multi-site routing) |
| Abuse | CrowdSec (Caddy acquis); optional firewall bouncer `--profile enforce` |
| Agent | Heartbeat + **site-map sync** + access-log event ship + Caddy reload |
| Control plane | Nodes / sites / events / customer site list |

Lab VM: **116** `niktiar-secure-edge` @ `192.168.0.217` (shared mode by default).

---

## 2. Hybrid multi-tenant model

| Mode | Who | Behaviour |
|---|---|---|
| **shared** (SMB default) | One edge hosts many tenants | Agent pulls all enabled sites where `edge_node_hostname IS NULL` **or** pinned to this node; routes by `Host` |
| **dedicated** (enterprise) | One edge ↔ one tenant | Agent pulls only that tenant’s sites (node `tenant_short_code` + optional pin) |

DNS: customer CNAME/A → shared edge IP (or dedicated appliance IP).  
NikTiar admin creates `secure_edge_sites` rows (`public_hostname` → `origin_url`).

## 3. APIs

### Appliance
- `POST /api/v1/secure-edge/heartbeat` — mode + capabilities  
- `GET /api/v1/secure-edge/config?hostname=&mode=` — site map + `config_version`  
- `POST /api/v1/secure-edge/events` — WAF/block signals  

Optional Bearer = node `appliance_token` (issue via admin).

### Admin
- `GET /admin/secure-edge/nodes`  
- `POST /admin/secure-edge/nodes/{hostname}/token`  
- `GET|POST /admin/secure-edge/sites` · `PATCH|DELETE .../sites/{id}`  
- `GET /admin/secure-edge/events`  

### Customer
- `GET /customer/secure-edge/{short_code}/sites`

**Catalog:** `secure_edge_waf` · entitlement `secure_edge_enabled`.

## 5. Ops

```bash
# VM 116
cd /opt/niktiar-secure-edge/docker
sudo docker compose --env-file .env up -d --build
curl -s http://127.0.0.1/healthz
# Host-based site (after admin creates site)
curl -s -H 'Host: demo.secure-edge.lab' http://127.0.0.1/
```

Create a lab site (from control host, with SOC JWT):

```bash
POST /admin/secure-edge/sites
{
  "tenant_short_code": "DEMO",
  "public_hostname": "demo.secure-edge.lab",
  "origin_url": "http://origin:80",
  "tls_mode": "http_only"
}
```

Dedicated enterprise edge: set VM env `SECURE_EDGE_MODE=dedicated` + `NIKTIAR_TENANT_CODE=ACME` and pin sites with `edge_node_hostname`.
