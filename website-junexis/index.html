Mode 1: Cloud without Appliance

Direct cloud agent streaming. Agents in your cloud stream security signals to the Kevantic managed SOC. No edge box on site — long-term retention follows the cloud Data Lake path under your retention policy.

  • Best for cloud-native estates comfortable with SOC-bound telemetry
  • Fastest path to fully managed monitoring
  • Same customer portal and service menu

Mode 2: Cloud with Appliance

Cloud estate + edge metadata filter. Cloud workloads plus a Kevantic Edge Appliance that forwards only allowed metadata and alerts to the SOC over encrypted TLS.

  • Policy control before data leaves the boundary
  • Less raw exposure than direct ingest
  • Ideal when cloud apps meet stricter data rules

Mode 4: On-Prem with Appliance

Flagship Edge Appliance. A Kevantic Edge Appliance in your datacenter. 100% raw logs remain local. Only required metadata and alerts stream to the Kevantic SOC over encrypted TLS. Retrospective hunts can run on your site.

  • Built for “we will not ship complete logs to a vendor cloud”
  • Data residency without giving up a managed SOC
  • We provision and operate the appliance as part of the service
